# Development Guide

- Commit rule: [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
- Branch Rule: Git flow
  ![](https://gitbook.tw/images/tw/gitflow/why-need-git-flow/flow.png)
  - Create feature or fix branch when needed
  - Request a **Pull Request** when feature/fix is done.
  - Always use PRs to merge into `main`.
  - Checkout release branch or tag for specific checkpoint.
